# TokenCalc - LLM VRAM Estimator

TokenCalc is a precision-engineered infrastructure planning platform for Large Language Models. It provides mission-critical tools for estimating GPU memory requirements, KV Cache footprints, and quantization tradeoffs for local and enterprise AI deployments.

## 🛡️ Core Mandates
- **Hardware Precision**: Client-side JavaScript engine for calculating VRAM requirements based on transformer architecture block logic.
- **Privacy Centric**: All infrastructure planning remains local to your browser; no proprietary model weights, prompt data, or corporate AI roadmaps are transmitted or stored.
- **Enterprise Ready**: Designed for AI architects, data engineers, and hardware procurement specialists.
- **CLS Prevention**: Strict structural ID hooks (`#slot-lead-billboard`, `#slot-sidebar-skyscraper`) enforce layout stability for AdSense integration.

## 🚀 Getting Started
1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Verify `ads.txt` in the `/public` directory.

## 📂 Architecture
- `/src/app/articles`: LLM Infrastructure Knowledge Base index and articles.
- `/src/components/llm-vram-estimator.tsx`: Core VRAM simulation engine.
- `/src/app/legal`: Sanitized legal pages (Privacy, Disclaimer, Rights) tailored for hardware simulation and AI governance.
